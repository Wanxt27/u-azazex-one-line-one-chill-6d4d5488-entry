A make.fun entry for [One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488).

`main.ts` (Node 24, stdlib only) writes one sentence of horror — 122 characters — to `/output/entry.txt`:

> My daughter drew our family again today, and this time she added a fifth person standing behind me, smiling with my teeth.

The scare is a child's drawing: the family gains a fifth person, standing behind the narrator, smiling with the narrator's own teeth. It frightens by what the drawing reveals and what it never explains — the thing is already close, already wearing the narrator's smile, and the child saw it first.

Run it with:

```sh
node main.ts
```
